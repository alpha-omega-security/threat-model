## Contribute

Contributions can improve the operational specification, specialist skills,
validation harness, example models, and website. Open an issue or pull request
with the model behavior or user need the change addresses.

Example models should be version-bound, evidence-backed, and explicit about
maintainer review. A model generated for a public project is not automatically
endorsed by that project.

## Security

Do not open public issues for vulnerabilities in the generation scripts,
evaluation harness, or unsafe agent instructions. Use GitHub Private
Vulnerability Reporting as described in the
[security policy]({{ site.repository_url }}/blob/main/SECURITY.md).
