# Threat-model batch targets — one repository URL per line.
# Blank lines and lines starting with '#' are ignored.
# An optional second token pins a git ref (branch, tag, or commit).
# key=value tokens set per-target generator options: ref=, subdir=,
# osv-package=<ecosystem>:<name>, context-url=<url> (repeatable).
# The last two feed the security-context fetcher; enable it batch-wide with
# "extra_args": ["--fetch-security-context"] in the configs file.
#
# Five packages per ecosystem, chosen to be widely depended on but small enough
# to model in one pass — parsers, decoders, HTTP clients and serializers, where
# the security contract is the interesting part. Deliberately no browser
# engines, kernels or crypto monoliths: those need several models, not one.
#
# osv-package uses OSV's ecosystem names (npm, PyPI, NuGet, Maven, Ubuntu).
# Only the first colon separates ecosystem from name, so Maven's
# groupId:artifactId passes through intact.
